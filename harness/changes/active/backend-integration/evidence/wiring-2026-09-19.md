# Wiring result — 2026-09-19

Every product screen now reads from the live backend through `src/data/*` (Resource = SQLite cache + network, stale-while-revalidate). Demo data removed from product code (`src/demo/demo-data.ts`, `demo-bundle.ts` deleted; `demoGradeForPercent` replaced by the teacher's scale).

| Screen | Source now |
|---|---|
| Onboarding (new) | `POST /auth/device-handshake` → profile + grading scale in kv; identity in SecureStore |
| Home | classes, tests, roster, submissions (server + local outbox), class analytics → top topic |
| Checking | submissions merged with local outbox states; scan disabled without class/assignment |
| Scan / identify / result / save | bundle catalog from `/offline-bundle` (cached; unknown sheet → fetched once); roster of the active class; real `classId`; grade from teacher scale; save → outbox → `batch-sync` |
| Classes (+ class form) | `GET /classes`, roster, `bulk-import` (creates class / adds students), class analytics |
| Assignments (+ test form) | `ready-tests`, task bank, `POST /constructor/tests` (returns the bundle, cached), `blank.pdf` → share sheet |
| Analytics | class analytics; dynamics derived from per-test submissions; topics ranked; grade distribution; no per-student ranking |
| Export | `gradebook.xlsx|csv` → cache → share sheet |
| More | class summary from context |

Default sync target is the live server (`EXPO_PUBLIC_API_URL` overrides; `fake` = lab only).

## Known limits (backend-imposed)
- «На проверку» count is not tracked server-side → the metric is not shown (was demo).
- Test list is server-wide; assignment↔class link does not exist → «Тесты» shows all tests, progress is per (class, assignment) from submissions.
- Seeded `TAT-2026-Q1` has no bundle (500): shown, but no PDF/scan.
- Sheets scanned before the class roster exists cannot be saved (guard message).
