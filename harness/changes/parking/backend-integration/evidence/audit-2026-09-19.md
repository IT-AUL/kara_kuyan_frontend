Only the **outbox → `batch-sync`** path is really connected (and only when `EXPO_PUBLIC_API_URL` is set; otherwise `FakeGateway`). Every screen except the scan flow reads `src/demo/*` or literals. The API layer (`BackendApi`) exists but **no screen calls it**.

## Mocks and leftovers to remove
`src/demo/{demo-data,demo-bundle,*.fixture.json}` (kept only for tests/lab), `FakeGateway` in composition, `MemoryStore` (tests only), `DEMO_CLASS_ID`, `demoGradeForPercent` in the product path, literal class/teacher strings in screens, `Button`s with `onPress={() => {}}` (Assignments «Создать тест», Classes «Добавить ученика», «Подобрать упражнения»).

## Backend limits that shape the design (not bugs to wait on)
- No endpoint to list assignments per class; `ready-tests` is global to the server (not scoped to the teacher — observed).
- No time-series analytics: derive from submissions.
- Class creation is implicit via `bulk-import`; no rename/delete; students only added.
- Any UUID self-registers; identity is a demo bearer.
- Seeded `TAT-2026-Q1` bundle 500 → use constructor-created assignments.
- Server flaps (502) → every screen needs loading/offline/error states and the outbox already covers writes.

## Plan to remove all mocks (order)
1. **Session + identity:** handshake on first run, teacher/school/scale in state; onboarding form (name, school) — no auth screens beyond that (hackathon scope).
2. **Roster + classes:** repository (API → SQLite cache, migration v2), Classes screen live, add students.
3. **Bundles:** repository + cache; Scan template and `evaluateSheet` catalog from it; Assignments list/create/print.
4. **Save path:** real `classId`/`student_id`; default gateway = HTTP.
5. **Read side:** Home/Checking/Analytics/Export from `GET /submissions` + analytics endpoints + gradebook download.
6. **Cleanup + states:** delete demo usage from product code, loading/empty/error/offline states, retry, e2e on the phone against the live server.
Each step: tests (fake `ApiClient`), live contract test extended, device evidence.
