## Почему старая аналитика была пустой
Она показывала **числа** («76%», «4,0»), но не отвечала ни на один вопрос учителя и не вела к действию. Исследования это подтверждают: учителя жалуются на «много данных и нет времени» (Data Quality Campaign, Gates). Все сильные продукты (ZipGrade, Kahoot, Google Forms, Quizizz, Khan) сводят аналитику к одной формуле:

> **Порог → кто и как ошибся → действие в один тап.**

## Принцип: каждый экран отвечает на один вопрос учителя

| Уровень | Вопрос учителя | Экран | Главный визуал | Действие |
|---|---|---|---|---|
| Неделя | Где нужна моя помощь? | Аналитика (вкладка) | «3 дела на неделю» + классы со спарклайном | Перейти к делу |
| Работа | Как написали, что делать на уроке? | Итоги контрольной | Полоса 5/4/3/2, качество, «План на урок» | Всем классом / группе / лично |
| Задание | Почему ошиблись? | Разбор задания | Топ неверных записей с подсветкой ошибочной буквы и тегом правила | Тренировка только этой группе |
| Класс | Проблема общая или частная? | Карта класса | Тепловая карта ученик × задание | Тап по столбцу → кто ошибся |
| Класс | Какие буквы путают? | Буквы класса | Карта татарского алфавита по % ошибок | Диктант на букву |
| Ученик | Растёт ли и над чем работать? | Профиль | Линия результатов против среднего по классу + вывод словами | Карточка ученику |
| Отчёт | Как сдать анализ за минуту? | Анализ для завуча | Документ по шаблону завуча | PDF / Word |

## Правила, зашитые в дизайн
- **Пороги решения:** верно меньше 50% — повторять всем классом, 50–80% — работа в группах, от 80% — тема усвоена. Отсечка 50% взята из шаблонов завучей, 80% — у Уильяма.
- **Группировка по одинаковой ошибке**, а не по баллу.
- **Формулы завуча** (N — сколько писали):
  - качество = (n5 + n4) / N;
  - успеваемость = (n5 + n4 + n3) / N;
  - СОУ = (n5 + 0,64·n4 + 0,36·n3 + 0,16·n2) / N.
- **Таксономия ошибок татарского:** сингармонизм, татарская буква (ә ө ү җ ң һ), начальный звук аффикса (к/г, д/т), пропуск.
- **Почерк — только флаг** «проверьте распознавание», а не метрика.

## Визуальный язык
Цвета оценок: 5 — зелёный, 4 — голубой, 3 — янтарный, 2 — коралловый. Цвета зон: красная, янтарная, зелёная. У каждого правила свой цвет тега. Свечение и градиенты на главных карточках сделаны в духе Oura и WHOOP. Анимации: count-up, полосы растут, линия прорисовывается. Референсы: [SchoolAI](https://mobbin.com/screens/00828d09-252c-4d02-92a1-58966ebbe19d), [Oura](https://mobbin.com/screens/3d206be7-b48f-4e5d-8168-3848a611e105), [Bevel](https://mobbin.com/screens/953c3a4c-960d-4fdd-98cc-3a0a7bac470b), [WHOOP](https://mobbin.com/screens/2576c34c-186e-4b65-a8b1-5cc95ab79cad), [pliability](https://mobbin.com/screens/7fcf70e5-690c-4979-8c97-d0e69aa569d8).

## Что даёт текущий API
✅ Работает уже сейчас:
- проблемные задания (`accuracy_pct`);
- типичные неверные ответы и кто ошибся (`wrong_submissions`);
- слабые темы класса (`top_class_mistakes`);
- трудные буквы (`difficult_characters_across_class`);
- профиль ученика (`history`, `frequent_weak_topics`, `problematic_letters`);
- таблица успеваемости.

> [!IMPORTANT]
> **Открытые вопросы к бэкенду.** Семантику я не выдумывал, это нужно согласовать:
> 1. Оценки 5/4/3/2 по **конкретной работе**. Без них нет качества и успеваемости по работе, а это главный отчёт завуча.
> 2. Список сдавших и отсутствовавших по работе. Нужен для тепловой карты и шапки отчёта.
> 3. Связь задание → тема/умение (КЭС). Нужна для поэлементного анализа.
> 4. Тип ошибки или правило по каждому неверному ответу (сингармонизм, буква…). Классифицировать должен сервер.
> 5. Уверенность OCR по ответу: ошибся ученик или распознавание.
> 6. История класса (средний результат и качество по работам). Нужна для трендов.
> 7. `common_confusions` в агрегате по классу (сейчас есть только по ученику).
> 8. Частичные баллы и максимальный балл за задание.
> 9. Как считается `top_class_mistakes`: кто размечает темы и что лежит в знаменателе.
